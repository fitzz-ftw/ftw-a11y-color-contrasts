# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-10-01

### Added
- Initial release of the WCAG-compliant color selection Web Component.
- Core HSL color logic with "Hue Persistence" to prevent achromatic collapse (powered by `culori`).
- TypeDoc documentation and happiest-dom test suite.
- ISC License and CDN-ready ESM distribution via `esm.sh`.
